## 修复新版 GitHub 网页导入

1.0.1 在 GitHub 新版导入页面上会提示“未找到完整的 GitHub 导入表单”并停止。1.0.2 已适配新版页面，保留原有 Private 校验，并同时检查 GitHub 自己显示的私有状态。未知表单仍然停止，新版表单不会退回普通 GET 提交。

真实登录浏览器测试已完成导入，GitHub 明确显示完成；通过 API 和 Git 再次确认目标为独立私有仓库，分支、标签、对象 ID 和默认分支与源一致，未登录访问返回 404。65 项自动测试通过。真实 LFS 数据迁移尚未验证。

下载附件 **github-fork-to-private-1.0.2.zip**，解压后在 `chrome://extensions` 开启开发者模式，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的目录。已安装用户请更新原目录文件，点击「重新加载」，确认版本为 1.0.2，再刷新 GitHub 页面。请保留安装目录。

包内包含中文、英文 README 和中文安装说明，不需要 Git、Node.js 或 npm 即可加载扩展；可选的本地复制功能另需 Git 和 GitHub CLI。

## English

Version 1.0.2 fixes the “import form not found” stop on GitHub's current import page. It checks both the Private radio selection and GitHub's rendered visibility state, rejects unknown forms, and prevents native GET submission for the React form.

A real signed-in browser import completed successfully. API and Git checks confirmed an independent private repository with matching branches, tags, object IDs, and default branch; unauthenticated access returned 404. All 65 automated tests passed. Real LFS object migration remains unverified.

Download **github-fork-to-private-1.0.2.zip**, extract it, enable Developer mode at `chrome://extensions`, and choose **Load unpacked**. Select the folder containing `manifest.json` and keep it in place. To update, replace the files in the original installation folder, click **Reload**, confirm version 1.0.2, and refresh GitHub pages. Both Chinese and English README files are included. The extension interface remains Chinese.
