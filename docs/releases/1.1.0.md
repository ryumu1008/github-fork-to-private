# 1.1.0 — 点一次，自动复制到 Private / One-click private copy

## 中文

- 仓库页点击“复制到私有”直接开始，自动使用原仓库名加默认后缀；自定义名称、上游选择和终端命令保留在“更多选项”。插件弹窗默认隐藏可选填写项。
- 同名时自动尝试 -2、-3 等编号，最多 20 个名称，不覆盖已有仓库；手动指定的名称冲突时停止。
- 先确认 GitHub 的 Private 状态，再逐项填写并核对页面回写的地址、名称及名称可用提示。只在准备阶段有限重试，保留提交前的安全检查。
- 仓库按钮发起的导入页留在同一个浏览器窗口，避免多窗口时跳到别处。
- 76 项自动测试通过；真实浏览器的一键复制及同名改名均完成，目标为独立私有仓库，1 个分支和 2 个标签的全部对象 ID 与源一致，匿名访问返回 404。

下载 ZIP、解压并更新原扩展目录，在 chrome://extensions 重新加载并确认 1.1.0，再刷新 GitHub 页面。默认三秒自动提交；以前关闭自动提交的设置仍然保留。

公开源仓库无需 Token；私有源可能需要额外认证。云端导入不含 LFS、Issues、PR 等平台数据，最终结果以 GitHub 页面为准。

## English

- The repository button starts immediately with the original name plus the saved suffix. Custom names, upstream selection, and terminal commands remain under More options; optional inputs are collapsed in the popup.
- Name collisions automatically try -2, -3, etc., up to 20 candidates, without overwriting existing repositories. Conflicting custom names stop instead.
- Waits for GitHub's Private state, then fills and checks controlled input values and name availability. Retries are bounded and limited to preparation; pre-submit checks remain enforced.
- Imports started from repository pages open in the same browser window.
- All 76 automated tests passed. Live default and collision imports completed as independent private repositories, with all object IDs for 1 branch and 2 tags matching the source and anonymous access returning 404.

Extract the ZIP into the installed extension directory, reload at chrome://extensions, confirm version 1.1.0, and refresh GitHub pages. Automatic submission defaults to three seconds; existing disabled auto-submit settings remain respected.

Public sources need no token; private sources may require authentication. Cloud import excludes LFS objects, Issues, PRs, and other platform data. Check GitHub's result page for completion.
